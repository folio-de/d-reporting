# 4. Entleihende

## Beschreibung 
Jede eingetragene Person/Institution ist nur einmal zu zählen und nur dann, wenn sie aus der Bibliothek tatsächlich im
Berichtsjahr entliehen hat.

## Hinweis
Um die Beantwortung der Frage trotz aktivierter Anonymisierung der Ausleihhistorie zu ermöglichen wurde im BVB ein Automatismus eingeführt, der ein Multiselect-Custom-Field befüllt (z.B. 2026) sobald ein User in diesem Jahr Ausleihen getätigt hat. Beispiel: <br>
